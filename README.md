# Simple-Designed-Forume (UFounded)

Современный форум и маркетплейс цифровых аккаунтов в фирменном тёмно-синем стиле с компоновкой разделов в духе **Radmir / XenForo**, отдельным маркетплейсом в стиле **LZT Market**, тикет-системой и **invite-only регистрацией**.

![Интерфейс форума UFounded](screenshots/preview.png)

---

## 🌟 Ключевые возможности проекта

### 1. Форум в стиле Radmir / XenForo
- **Блочная компоновка категорий (`.cat-block`)**: разделы разбиты по смысловым группам (*«Главное»*, *«Игры и софт»*, *«Разработка и маркет»*) с акцентными шапками и счётчиками.
- **Богатые ноды разделов (`.forum-node`)**:
  - Тематические squircle-иконки разделов с индивидуальной подсветкой.
  - Название и описание раздела.
  - Колонки со статистикой (*Темы* и *Сообщения*).
  - Колонка последней активности: аватарка автора последнего сообщения, кликабельное название темы, время публикации и ник автора со ссылкой на профиль.
- **Модульный сайдбар виджетов (`.widget-card`)**:
  - ⚡ **«Новые сообщения»** — лента свежих тем со счётчиками ответов и тегами разделов.
  - 📊 **«Статистика форума»** — аккуратный список метрик (*Темы*, *Сообщения*, *Пользователи*, *Новый участник*).
  - 🟢 **«Сейчас на форуме»** — активные пользователи с цветными точками ролей (*администратор*, *модератор*, *пользователь*).
  - 💬 **«Сообщество UFounded»** — быстрые кнопки (*Поддержка*, *Участники*, *Чат / ЛС*, *Правила*).
- **Полоса под-навигации (`.subnav-bar`)**: навигационные вкладки (*«Разделы форума»*, *«Маркет»*, *«Новости»*, *«Пользователи»*, *«Поддержка»*) и кнопка *«+ Создать тему»*.

---

### 2. Встроенный Маркетплейс (в стиле LZT Market)
- **Отдельная страница маркета (`#/market`)**:
  - Доступ через главную навигацию, полосу разделов и баннер на главной странице.
  - Интерактивный баланс пользователя в шапке с кнопкой быстрого пополнения.
- **Лента платформ и игр**:
  - Быстрые фильтры с векторными иконками: *CS 2*, *Steam*, *Telegram*, *Discord*, *Epic Games*, *Valorant*, *Fortnite*, *Genshin Impact*, *Minecraft / Другое*, *Услуги и софт*.
- **Поиск и расширенная фильтрация**:
  - Поиск по ключевым словам в названии и описании.
  - Диапазон цен (*От ... До ... ₽*).
  - Фильтр по происхождению (*Личный*, *Перепродажа*, *Авторег*, *Брут*, *Фишинг*, *Стиллер*) с цветными бейджами.
  - Фильтр по сроку гарантии (*24 часа*, *12 часов*, *3 дня*, *На момент покупки*).
  - Сортировка (*Сначала новые*, *Сначала дешевые*, *Сначала дорогие*, *По просмотрам*).
  - Вкладки каталога: *«Каталог товаров»*, *«Мои объявления»*, *«Мои покупки»*.
- **Выставление аккаунтов на продажу (`+ Продать аккаунт`)**:
  - Модальное окно создания лота: платформа, заголовок, цена, происхождение, гарантия, описание.
  - Поле **«Данные для покупателя»** (логин, пароль, почта, токен), которое безопасно хранится на сервере и передаётся покупателю только в момент успешной оплаты.
- **Покупка и безопасная сделка**:
  - Проверка баланса покупателя, списание средств и начисление продавцу.
  - Моментальная выдача данных от купленного аккаунта с кнопкой *«Скопировать данные»*.
  - Постоянный доступ к купленным данным на странице лота и во вкладке *«Мои покупки»*.
- **Без чекеров и автоматических смен паролей**:
  - Строго соблюдён принцип прямой безопасной сделки без сторонней автоматической валидации и вмешательства в пароли.

### 3. Инвайт-система и приватность
- Регистрация строго по действующим пригласительным кодам.
- Создание кодов доступно исключительно администратору с указанием лимита использований и срока действия.
- Логирование использований кодов.

---

### 4. Профиль, Социальные функции и Поддержка
- **Страница профиля (`#/profile`)**: дата регистрации, статистика тем и ответов, редактирование аватара и описания.
- **Личные сообщения (`#/messages`)**: диалоги между пользователями в реальном времени.
- **Тикет-система (`#/support`)**: обращения в техническую поддержку для связи с модераторами и администрацией.

---

### 5. Модерация и безопасность
- Премодерация новых публикаций с одобрением/отклонением администрацией.
- Санкции: блокировка пользователей, временное ограничение на создание постов.
- Роли: Администратор, Модератор, Саппорт, Пользователь.

## 🚀 Быстрый запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера
npm start
```

Откройте в браузере: **[http://localhost:3000](http://localhost:3000)**

- **Учётная запись администратора**:
  - Логин: `ask`
  - Пароль: `1122`
- **Инвайт-код для регистрации новых пользователей**:
  - `SKEETBESTCHEAT` (или сгенерируйте новые коды в панели *«Админ»* → *«Инвайты»*)

## 🛠️ Архитектура и технологии

- **Backend**: Node.js + Express (без тяжёлых нативных зависимостей).
- **База данных**: локальное JSON-хранилище `data.json` с автоинициализацией.
- **Аутентификация**: хэширование паролей `bcryptjs`, токены `jsonwebtoken` (JWT, 14 дней), безопасная передача приватных данных.
- **Frontend**: Single Page Application (SPA) на чистом JavaScript, стилизация на нативном CSS с адаптивной сеткой под мобильные устройства и десктоп.

### Основные API эндпоинты

#### Маркетплейс
- `GET /api/market` — список товаров с параметрами поиска, категорий, цен и фильтров
- `GET /api/market/:id` — детальная информация о товаре (приватные данные выдаются только покупателю или продавцу)
- `POST /api/market` — публикация нового аккаунта на маркете
- `POST /api/market/:id/buy` — покупка аккаунта с внутреннего баланса
- `DELETE /api/market/:id` — удаление/снятие товара с продажи
- `POST /api/market/deposit` — быстрое пополнение баланса для тестирования

#### Форум и посты
- `GET /api/forums` — категории и разделы со статистикой и последними темами
- `GET /api/forums/:id/threads` — темы раздела
- `POST /api/forums/:id/threads` — создание темы
- `GET /api/threads/:id` — просмотр темы и сообщений
- `POST /api/threads/:id/posts` — ответ в тему

#### Пользователи и инвайты
- `POST /api/register` — регистрация по инвайт-коду
- `POST /api/login` — вход в аккаунт
- `GET /api/me`, `PUT /api/me/profile` — данные и редактирование профиля
- `POST /api/admin/invites` — создание инвайт-кода администратором
- `GET /api/admin/invites` — список всех пригласительных кодов
